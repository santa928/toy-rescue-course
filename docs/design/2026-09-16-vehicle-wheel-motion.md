# 全5車種の走行時の足回り

全5車種の足回りが車体へ固定され、滑って移動して見える不具合を修正する。
世界観は「積み木の街・角ばったおもちゃの車・見て分かる動き」。各タイヤへ短いスポークを入れ、既存ボクセルを車軸の周りで回転させる。
ブルドーザー・ショベルカーは既存の履帯外形に沿って踏み板を循環させ、明るい筋で動きを見せる。

## 要件差分（ユーザーの対象範囲訂正を反映）

| 要件 | 状態 | 内容 |
| --- | --- | --- |
| REQ-001 | 維持 | 消防車・救急車・パトカーの4輪回転 |
| REQ-002 | 維持 | 実移動距離への連動と停止時の空転防止 |
| REQ-003 | 維持 | リセット・乗換の初期化、展示時の静止 |
| REQ-004 | 維持 | PC・横向きモバイルの実描画確認 |
| REQ-005 | 追加 | ブルドーザー・ショベルカーの左右履帯の循環 |
| REQ-006 | 追加 | 実旋回角から左右の履帯移動差を計算する |
| REQ-007 | 追加 | 既存GitHub Pagesへ公開し、公開URLの全5車種を確認する |

初版で誤って非対象にした2車種を対象へ戻す。既存要件の保留・削除はない。

## 受け入れ条件

- 3車種の左右前後4輪が回り、車体・灯火・道具は回転しない。
- Rapierの実移動距離を前後方向へ投影し、半径0.6の転がり角へ変換する。加減速に追従し、停止・壁への押し付け時に空転しない。
- 帰庫リセットと車種切替で回転角を初期化する。展示画面では静止する。
- PCと横向きモバイルの実走で、連続画像と実際のinstance行列を確認する。
- 履帯2車種は外周だけを循環させ、停止時に止まり、旋回時は左右で動く距離が変わる。内部転輪の位置とブレード・バケットの操作を維持する。

## 非対象

操作方法の変更、物理collider、ミッション、HUD配置、公開先の変更。

## リスクと対策

車体の部品まで回す誤分類を、実3モデルの84セルと車軸中心の単体テストで防ぐ。旋回中は車体前後方向の移動成分を使う。
回転時の外接変化に合わせて描画のbounding sphereへ余白を加える。停止・再発進・壁接触・reset・乗換はブラウザで確認する。
履帯では左右中心間隔2.4と実旋回角を使い、各側の移動距離を計算する。一周後の位置一致・正逆方向・停止・左右差・外周64/72セルの分類を単体テストで確認する。

## 性能目標・検証

色別InstancedMeshを維持し、追加draw callは0。毎frameのReact state更新やThree object生成をせず、車輪84セルまたは履帯64/72セルだけを更新する。
既存の関連造形・操作・色替えテストと型チェックを実行する。実走用のViteサーバに対し、Docker内で `node scripts/verify-vehicle-wheels.mjs` を実行する。
証拠は `output/vehicle-wheels/`。全ミッション・全ブラウザ・公開URLの検査は今回の局所的な描画修正の対象外とし、リリース時または影響範囲が拡がる場合に実施する。
履帯の実走は `node scripts/verify-vehicle-tracks.mjs`、証拠は `output/vehicle-tracks/`。2車種両画面の実行列、作業ボタン、リセット、およびPCの実壁への押し付けを確認する。
