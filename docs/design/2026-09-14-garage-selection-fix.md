# 車庫内での乗り換え判定修正

街の再構築で車庫を前庭の西へ移動した際、帰庫・乗り換え判定が元の駐車位置の半径3だけに残っていた。車庫へ入っても車種選択が表示されなかった。

車庫床 `garage-bay-floor` の描画座標と寸法から判定範囲を取得し、車庫内で停止したときも既存の5車種選択を表示する。元の前庭駐車位置での選択は維持し、乗り換えた車は従来どおり前庭から出発する。走行中の切替禁止と速度上限は変更しない。仕事完了後の帰庫判定も同じ範囲を使用する。

単体テストで修正前の不具合を再現し、実際の床内・床境界・壁の外側を検査する。既存の車庫実走テストに「内部で停止→選択表示→ボタンで別車種へ乗換→再入庫→出庫」を追加する。PCとスマホ横向きで検査し、代表1車種の経路を継続的なBrowser smokeにも含める。

造形・HUDの配置・物理挙動・描画予算は変更しない。実走証拠は `output/garage-selection/` に保存し、公開結果は今回のPRへ記録する。
