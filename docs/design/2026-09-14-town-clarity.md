# 遊びを維持した街の再構築

用途のない横棒・矢印看板・小箱が走行路に散在し、装飾なのか遊ぶ対象なのかが分かりにくかった。街角は、物を増やすための配置から、場所の用途を説明する配置へ変更する。

世界観辞書は「木の玩具を並べた、見通しのよい救援タウン」。道路は濃紺のプレイマット、地区は落ち着いた色の床、家は段屋根と玄関、公園は池・シーソー・ピクニック卓、工事場は事務所とクレーン・一か所の資材置き場。車・HUD・ミッション対象・言葉・演出は既存の働く車の語彙を維持する。新たな看板で説明を補わず、形と配置で用途を示す。

| 要件 | 状態 | 受け入れ条件 |
| --- | --- | --- |
| REQ-001 既存の遊び | 維持 | 5車種、15仕事、自由走行・自由アクション・色遊び6か所・壊せる積み木・車庫乗換を維持 |
| REQ-002 操作と車の表現 | 維持 | カメラ・HUD・操作・サウンド・前回改修した車モデルと演出を維持 |
| REQ-003 用途が読める街 | 追加 | 単なる棒・箱に見える小物を撤去し、脚のある家具、花の鉢、消火栓の口、座席と握りのある遊具へ整理 |
| REQ-004 開けた動線 | 追加 | 独立看板・柵・街灯・中央花壇を撤去。資材は工事場奥へ集約。住宅の玄関は中央広場へ向け、小道でつなぐ |
| REQ-005 描画と物理の整合 | 維持・強化 | 描画・当たり判定は同じbox定義。前庭の道路分割と交差点の中央線もcanonical道路から生成 |
| REQ-006 見つけられる対象 | 維持・強化 | 15仕事の最終進入路に遮蔽物がないunit検査、PC・スマホ横向きの実走と画像目視 |

既存要件の保留・削除はない。過去の「各地区に2〜4装飾群」という内部の個数基準は、遊び場へ不要物を再投入しないよう撤廃する。各地区の床・遊ぶ対象・自由な移動範囲は維持する。

非対象はゲームルール、難易度、車体、UI配置、課金・依存追加、公開先変更。性能目標はscene34 draw以内と既存bundle予算を維持し、固定colliderを40から22へ削減する（上限24）。背景は既存InstancedMeshの1 batchで描く。

主なリスクは家具や遊具による隠れ・引っ掛かり、削除した座標に依存する検証スクリプト、描画と接触位置のずれ。配置テスト、開放路の通過・残した大物の衝突・仕事の達成・車庫乗換の実ブラウザ検査で確認する。物理端末での手触りと幼児による理解確認は、ブラウザ検証と区別する。

公開は既存GitHub Pagesへ、レビュー済みPRのmergeで行う。復旧はこの変更のrevertをPagesへ再配信する。
