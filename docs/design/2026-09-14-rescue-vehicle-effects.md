# 働く車の車高と演出の見直し

パトカーが扁平に見えること、消防車・救急車・パトカーの演出が分かりにくいという報告に対応する。特に救急車とパトカーの形と反応を優先する。

世界観辞書は「積み木の働く車」。車体は大きな窓・タイヤ・仕事の道具で識別できる玩具、背景と道路は既存の箱庭、HUDとボタンは同じ車の絵と道具名、演出は水・ハート・灯火から生まれる波で統一する。動く部品を車体から離して膨らませない。

| 要件 | 状態 | 受け入れ条件 |
| --- | --- | --- |
| REQ-001 パトカーの車高 | 変更 | 肩を1段、車室を2段高くし、2段の窓と屋根灯が読める。実voxel外接をHUD寸法が包含する |
| REQ-002 救急車 | 変更 | 車体の十字を固定し、穏やかな灯火と前方の一つのハート・ケア波で押下へ反応する |
| REQ-003 パトカー | 変更 | 車体灯を固定し、赤青の左右波と0.5秒の交互点灯でサイレンを示す。走行時だけ短い軌跡を出す |
| REQ-004 消防車 | 変更 | 保持中はノズルから水流がつながり、自由放水は弧を描いて地面に着水する。炎への照準と成功判定は維持する |
| REQ-005 既存の遊び | 維持 | 5車種、全15仕事、自由走行、色遊び、破壊、車庫乗換、押下・保持・解除、音ON/OFFを維持する |

非対象は街の配置・物理collider・ミッションの達成条件・公開先変更。画像素材や追加依存は不要で、ボクセル形状を実ブラウザで直接比較する。

性能目標は固定48slot/1 drawの共通演出、水32slot、車体7 draw以内、scene34 draw以内を維持する。車体を高くした際のHUD・車庫干渉は外接テストと入庫実走、演出が役割として読めないリスクはPC/スマホ横向きの連続スクリーンショット、操作解除の残留は状態と固定poolの検査で確認する。実機の音質・幼児の理解はブラウザ自動検査の結果と区別する。
